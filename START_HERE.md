# Начни отсюда — Go Messenger

Это готовый **учебный MVP**. Я собрал его по нашей переписке: регистрируйся, входи, отправляй сообщения в общий и личные чаты. История хранится в PostgreSQL.

## За 3 команды на Windows

1. Сделай копию **старой папки проекта**. Не удаляй Docker volume с БД.
2. Останови старый Go-сервер в VS Code через `Ctrl+C` (у тебя раньше порт `8080` был занят).
3. Распакуй архив и открой терминал **в папке, где находится `compose.yaml`**.
4. Docker Desktop должен показывать `Engine running`.

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=40 app
```

Открой **http://localhost:8080**. Входи под ранее созданным `alex123` со своим паролем или зарегистрируй нового пользователя. Если старый том Compose назывался `go-messenger_postgres_data`, прежние сообщения сохранятся.

**Важно:** не запускай `docker compose down -v` — так удаляются данные PostgreSQL.

## Если сервер не запускается

- `bind: address already in use` — останови старый Go-сервер через `Ctrl+C`.
- Ошибка подключения к Docker — запусти Docker Desktop.
- `DATABASE_URL не задан` — запускать через `docker compose up -d --build`, а не `go run` без переменных.
- В первый раз требуется Интернет, чтобы скачать образы и Go-модули.

## Опубликовать в Интернете

Понадобятся **домен** и **VPS с Linux**. Конфигурация `compose.prod.yaml` и Caddy для HTTPS лежат в архиве. Все шаги находятся в `README.md`, раздел «Публикация на VPS».

**Не публикуй личные данные пользователей, пока не сделаешь бэкап и проверку безопасности.** Это не приложение со сквозным шифрованием.
